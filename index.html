⚙️ Настройки

Получите ключ на openrouter.ai/keys. Ключ хранится только в localStorage браузера.

Оркестратор gemini-3.1-flash-lite-preview автоматически выбирает лучшую модель под каждый запрос:
🔢 Математика → deepseek/deepseek-v4-pro
💻 Код / Агент → anthropic/claude-4.6-sonnet
🖼️ Изображения → google/gemini-3.1-pro-preview
💬 Разговор → x-ai/grok-4.3

Выбор модели происходит автоматически. Текущая модель отображается в шапке.

В API отправляются последние 10 сообщений. Полная история сохраняется в chats.db и восстанавливается при перезапуске.

Используется встроенный Web Speech API браузера. Нажмите кнопку 🎤 рядом с полем ввода, произнесите текст — он автоматически вставится в поле. Повторное нажатие останавливает запись.

⚠️ Требуется Chromium-браузер (Edge / Chrome). В Firefox не поддерживается.
