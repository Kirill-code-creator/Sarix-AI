# 🌌 Sarix (NeuralChat v5.0) — Lightweight AI Desktop Agent

Sarix — это автономный десктопный ИИ-ассистент, построенный на архитектуре Local Web App. Он объединяет мощь лучших LLM 2026 года с полным контролем над операционной системой пользователя через безопасный интерфейс.

Вместо того чтобы привязываться к одной модели, Sarix использует **умный оркестратор**, который анализирует запрос и на лету маршрутизирует его к наиболее подходящей нейросети (Claude, DeepSeek, Grok или Gemini).

Ключевые особенности

Smart Auto-Routing: Встроенный диспетчер на базе `Gemini 3.1 Flash` мгновенно классифицирует запросы. Математика уходит в `DeepSeek v4 Pro`, программирование и агентика — в `Claude 4.6 Sonnet`, а обычный диалог — в `Grok 4.3`.
Полный контроль над ОС: Агент умеет выполнять команды в терминале и управлять мышью/клавиатурой (через `pyautogui`). 
Security First (Confirmation Gate) Интегрирована система безопасности. Безопасные команды (`pip install`, `dir`) выполняются автоматически, а деструктивные действия (`rm`, `del`, клики мышью) блокируются и требуют ручного подтверждения через UI.
Vision & Multimodality: Возможность агента делать скриншоты экрана и анализировать их через `Gemini 3.1 Pro Vision`.
Голосовой интерфейс: Поддержка Web Speech API для диктовки запросов без использования клавиатуры.
Долгосрочная память: Вся история сессий локально сохраняется в легковесную базу данных `SQLite` (`chats.db`), обеспечивая непрерывность контекста между перезапусками.

## 🛠 Архитектура (Local Web App)

Проект отказывается от тяжеловесного Electron и устаревшего Tkinter в пользу современного и быстрого стека:
Backend: `Python 3.14`, `FastAPI`, `Uvicorn`, `asyncio`.
Frontend: HTML5 / CSS3 / Vanilla JS.
Graphics: Интерактивный 3D-фон (нейронные узлы), отрендеренный на GPU через `Three.js`.
Native Window: Фронтенд запускается через локальный сервер и отображается в системном Chromium-браузере (Edge/Chrome/Brave) в режиме `--app`, создавая ощущение нативного десктопного окна.
Distribution: Упаковано в единый переносимый `.exe` файл с помощью `PyInstaller`.

 BYOK (Bring Your Own Key)

Приложение уважает вашу приватность. Sarix не проксирует трафик через сторонние серверы. Все запросы идут напрямую через OpenRouter API. Пользователь сам вводит свой API-ключ в настройках интерфейса, и он хранится исключительно локально (`localStorage`).

Об авторе

Проект создан 16-летним разработчиком из Санкт-Петербурга. Основной фокус: создание прикладных ИИ-агентов, асинхронное программирование на Python и проектирование интерфейсов. Разработка Sarix — это часть пути к поступлению и профессиональному развитию в Высшей Школе Экономики (ВШЭ).
